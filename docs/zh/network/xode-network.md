# XODE 网络

XODE Blockchain 网络由多个核心组件构成，每个组件在区块链的运行以及其与更广泛的 Polkadot 生态系统的互操作性中发挥着各自独特的作用。以下是主要组件：

### 平行链

网络的核心是平行链本身。平行链是一条独立的区块链，通过指定的平行链插槽连接到 Polkadot/Kusama 中继链。平行链拥有各自的规则、共识机制和治理结构，可根据其特定的用例和需求进行定制。

### 平行链插槽

平行链插槽是 Polkadot/Kusama 中继链中分配给各个平行链的有限资源。获得平行链插槽后，平行链即可连接到中继链并参与 Polkadot 网络。插槽通过去中心化的拍卖机制获得，平行链项目通过竞拍 DOT/KSM 代币来获得一段指定期限的插槽。

### Polkadot/Kusama 中继链

中继链是 Polkadot 网络的核心，负责促进平行链之间的通信与互操作。它协调验证人之间的共识，管理网络安全，并促进平行链之间消息和资产的传递。

### 收集人

收集人负责代表平行链生成候选区块。他们收集交易、执行状态转换，并将其打包成区块，随后提交给验证人进行最终确认。收集人在维护平行链的运行和完整性方面发挥着至关重要的作用。

### 验证人

验证人负责在中继链上最终确认区块，并确保网络的安全与共识。他们通过提议和验证区块、质押 DOT/KSM 代币作为抵押，以及参与治理决策，来参与出块和共识过程。

### 消息传递协议

平行链之间以及平行链与中继链之间通过消息传递协议进行通信。该协议支持在平行链之间传递消息、资产和数据，从而实现整个 Polkadot 网络的互操作与协作。

### 跨链桥

跨链桥是促进平行链与外部区块链或网络之间通信的连接器。它们支持在不同区块链生态系统之间转移资产和数据，将平行链的覆盖范围和实用性扩展到 Polkadot 网络之外。

这些组件协同工作，在 Polkadot 网络内构建了一个充满活力且可互操作的生态系统，使平行链能够在保持自主性和主权的同时，相互协作、交换资产并共享安全性。

## XODE Blockchain 收集人节点与中继链验证人节点

![](../../network/images/xode-network-1.png)  
在 Polkadot 生态系统中的 XODE Blockchain 里，收集人与验证人之间的关系对网络的运行和安全至关重要。下面我们深入了解这些角色如何交互的技术细节：

### 收集人

* 收集人负责代表平行链生成候选区块。他们收集交易、执行状态转换，并将其打包成区块。  
* 收集人收集交易后，会将这些交易与其他必要数据（例如平行链的当前状态）一起编译成区块。  
* 收集人独立运行，通常与特定的平行链相关联。他们维护平行链状态的本地副本，并根据平行链共识机制所定义的规则执行交易。  
* 组装好区块后，收集人会将其广播到网络中以供验证。

### 验证人

* 验证人负责在 Polkadot 中继链上最终确认区块，并确保网络的安全与共识。  
* 在平行链的场景下，验证人在验证收集人生成的区块方面发挥着关键作用。他们核验交易的正确性、执行状态转换，并确保区块遵循 Polkadot 网络的规则和协议。  
* 验证人通过提议和验证区块来参与出块和共识过程。验证人是根据其在网络中的质押量以及作为可信验证人的声誉而被选中参与出块的。  
* 验证人通过核验收集人提交的区块中的交易，并基于平行链的当前状态执行这些交易，来验证这些区块。他们确保交易有效、状态转换正确，并且区块符合网络的共识规则。
