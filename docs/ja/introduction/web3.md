# Web3

Web3 とは、ブロックチェーン技術と暗号技術の原則に基づいて構築された、分散型でユーザー中心のインターネットというビジョンを指す用語です。これは、ソーシャルメディアプラットフォーム、検索エンジン、オンラインマーケットプレイスなどの中央集権的な事業者が支配する現在のウェブ（Web 2.0）からのパラダイムシフトを表しています。

Web3 では、データとデジタル資産の管理権が、中央集権的な管理者から個人へと移ります。Bitcoin、Ethereum、Polkadot、XODE などの暗号資産を支える基盤技術であるブロックチェーン技術は、この分散化を実現するうえで中心的な役割を果たします。スマートコントラクトは、契約条件が直接コードとして記述された、自動的に実行される契約であり、仲介者を必要とせずに自動化されたトランザクションややり取りを可能にします。

Web3 に関連する主な概念と技術には、分散型金融（DeFi）、非代替性トークン（NFT）、分散型自律組織（DAO）、分散型アプリケーション（DApps）などがあります。Web3 の目的は、ユーザーに力を与え、イノベーションを促進する、より透明で安全かつ包括的なインターネットを創り出すことです。

## 信頼と真実

### トラストレス

Web3 プラットフォームは、暗号技術の原則と分散型のコンセンサスメカニズムに依拠することで、当事者間の信頼の必要性を最小限に抑えることを目指しています。従来のシステムでは、トランザクションの仲介や情報の検証のために、銀行や政府などの中央集権的な機関に信頼が置かれることが一般的です。しかし Web3 では、トランザクションが透明かつ改ざん不可能な形で記録されるブロックチェーンや、仲介者を必要とせずに合意を自動的に実行するスマートコントラクトなどの技術を用いることで、信頼の必要性が最小化、あるいは排除されます。このトラストレスな性質により、参加者は信頼できる第三者に頼ることなく、互いに直接やり取りできます。

### 真実性

Web3 における真実性とは、ブロックチェーン上に保存された情報の正確性と完全性を指します。ブロックチェーン上のデータは不変で改ざん耐性があるため、一度記録されると変更や削除ができません。この特性により、ブロックチェーン上に保存された情報は真実で信頼できるものとみなされます。さらに、プルーフ・オブ・ステーク（PoS）やプルーフ・オブ・ワーク（PoW）などのコンセンサスメカニズムにより、ネットワークのすべての参加者がトランザクションの有効性とブロックチェーンの状態について合意することが保証され、データの真実性がさらに強化されます。

## 進化

![](../../introduction/images/web3-1.png)

### Web1（1990 年代 \- 2000 年代初頭）

* Web1 は「読み取り専用」のウェブとも呼ばれ、インターネットの黎明期に登場しました。主にテキストと基本的な HTML の書式で構成された静的なウェブページが特徴でした。  
* ウェブサイトは主に情報提供を目的としており、ユーザーの操作はコンテンツの閲覧に限られていました。  
* 例としては、Yahoo\!、GeoCities などの初期のウェブサイトや、Altavista、Lycos などの初期の検索エンジンが挙げられます。  
* 情報へのアクセスを可能にすることと、World Wide Web のインフラを構築することに重点が置かれていました。

### Web2（2000 年代半ば \- 現在）

* Web2 は「読み書き」のウェブとも呼ばれ、動的でインタラクティブな、ユーザー生成コンテンツへの移行を示しました。  
* Facebook、Twitter、YouTube などのソーシャルメディアプラットフォームが台頭し、ユーザーはコンテンツを作成・共有し、他者とつながり、オンラインコミュニティに参加できるようになりました。  
* Web2 は、ユーザー生成コンテンツ、ソーシャルネットワーキング、ブログ、電子商取引などの概念をもたらしました。  
* Google、Amazon、eBay などの企業がオンラインの世界を支配し、検索や広告からオンラインマーケットプレイスやクラウドコンピューティングまで、幅広いサービスを提供しました。  
* ユーザーエンゲージメント、コラボレーション、そして広告とデータ収集による収益化に重点が置かれていました。

### Web3（黎明期 \- 現在）

* Web3 は、ブロックチェーン技術と暗号技術の原則に基づいて構築された、分散型でユーザー中心のインターネットというビジョンを表しています。  
* 中央集権的な機関から個人へと力を移すことで、データプライバシー、セキュリティ、管理権に関する問題の解決を目指しています。  
* Web3 に関連する主な技術には、ブロックチェーン、スマートコントラクト、分散型金融（DeFi）、非代替性トークン（NFT）、分散型自律組織（DAO）、分散型アプリケーション（DApps）などがあります。  
* Web3 はトラストレス、透明性、包括性を推進し、仲介者を必要とせずに、ピアツーピアのトランザクション、自動化された合意、安全なデータ共有を可能にします。  
* Ethereum、Polkadot、XODE などのプラットフォームは Web3 のインフラ構築の最前線に立っており、開発者は中央の管理から独立して動作する分散型アプリケーションやサービスを作成できます。  
* Web3 はまだ発展の初期段階にありますが、所有権、ガバナンス、価値交換の新しいモデルを提供することで、金融、ゲーム、サプライチェーン管理など、さまざまな業界に革命をもたらす可能性を秘めています。
