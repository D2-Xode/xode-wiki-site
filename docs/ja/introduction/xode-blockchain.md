# XODE Blockchain

XODE Blockchain は、Polkadot リレーチェーンと並行して稼働する独立したブロックチェーン（パラチェーン 3417）です。XODE は Kusama のパラチェーン 3344 として始まり、その後 Polkadot へ移行しました（下記の[Kusama から Polkadot へ](#from-kusama-to-polkadot)を参照）。

### スケーラブル

XODE Blockchain は Polkadot ネットワークと統合されており、複数のトランザクションとスマートコントラクトの実行を同時に処理します。並行して稼働することで、XODE Blockchain はネットワーク全体のスループットとスケーラビリティを向上させ、従来のブロックチェーンアーキテクチャと比べて高いトランザクションスループットを実現します。

### 相互運用性

XODE Blockchain は、Polkadot リレーチェーンを介して Polkadot Asset Hub や他のパラチェーンなどのブロックチェーンと通信できます。この相互運用性により、異なるパラチェーン間だけでなく、Polkadot に接続された他のブロックチェーンネットワークとの間でも、資産、データ、メッセージをシームレスに交換できます。

### カスタマイズ性

XODE Blockchain は、独自の機能、コンセンサスメカニズム、ガバナンス構造、トークンエコノミーを備えています。この柔軟性により、開発者は分散型金融（DeFi）、非代替性トークン（NFT）、サプライチェーン管理、アイデンティティソリューションなど、特定のユースケースに合わせてブロックチェーンを調整できます。

### 共有セキュリティ

XODE Blockchain は、Polkadot ネットワークの共有セキュリティの恩恵を受けています。独自のバリデーターセットやセキュリティインフラを維持する代わりに、パラチェーンは Polkadot リレーチェーンのバリデーターに依存してトランザクションを保護し、ブロックチェーンの完全性を確保します。

### ガバナンス

XODE Blockchain は独自のガバナンスメカニズムを持ち、XON 保有者はプロトコルのアップグレード、パラメーターの調整、新機能の追加に関する意思決定プロセスに参加できます。これにより、XODE コミュニティはネットワークの進化について自律性と管理権を持つことができます。

## Kusama から Polkadot へ {#from-kusama-to-polkadot}

XODE Blockchain は当初、Kusama リレーチェーン上で para ID 3344 のパラチェーンとして稼働していました。その後 Polkadot リレーチェーンへ移行し、現在は para ID 3417 で稼働しています。XODE はもう Kusama のパラチェーンではありません。

<ParachainMigration />

| | 以前 | 現在 |
| --- | --- | --- |
| リレーチェーン | Kusama | Polkadot |
| Para ID | 3344 | 3417 |
| セキュリティの提供元 | Kusama のバリデーター | Polkadot のバリデーター |

ノードを運用する場合は、Polkadot のチェーンスペックを使用する [XODE ノード](/ja/network/xode-node) のガイドに従ってください。[XODE ノード（Kusama 3344）](/ja/network/xode-node-kusama-3344) のガイドは参考用として残しています。

## XODE Blockchain は Substrate を使用して構築されています

Substrate は Polkadot によって作られたブロックチェーン開発フレームワークです。カスタムブロックチェーンネットワークや分散型アプリケーション（DApps）を構築するための、強力で柔軟なプラットフォームを開発者に提供します。 

### モジュール性とカスタマイズ性

Substrate のモジュール式フレームワークを活用することで、XODE Blockchain はスケーラビリティ、プライバシー、ガバナンスなど、特定の要件を満たすようにブロックチェーンを調整できます。XODE Blockchain は、カスタムモジュールを容易に統合したり、既存のモジュールから選択したりして、機能を最適化できます。

### 効率性とパフォーマンス

Substrate の軽量で効率的な設計により、XODE Blockchain は高スループットかつ低レイテンシーで動作し、高速なトランザクション処理と優れたユーザー体験を実現します。この効率性は、XODE Blockchain が大量のトランザクションを効果的に処理するうえで不可欠です。

### 相互運用性

Substrate ベースのブロックチェーンである XODE Blockchain は、Polkadot エコシステム内の他のブロックチェーンとシームレスに接続・通信できます。この相互運用性により、異なるブロックチェーンネットワーク間で資産やデータを交換でき、XODE Blockchain の有用性と使いやすさが向上します。

### セキュリティ

XODE Blockchain は、組み込みのセキュリティメカニズム、暗号プリミティブ、安全な開発のためのベストプラクティスなど、Substrate の堅牢なセキュリティ機能を継承しています。これにより XODE Blockchain の完全性と信頼性が確保され、ユーザーの資産とデータが潜在的な脅威から保護されます。
