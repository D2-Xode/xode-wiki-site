# XON ユーティリティトークン

XODE Blockchain では、ネイティブユーティリティトークンは XON と呼ばれます。XON トークンはブロックチェーン内で次のような重要な機能を担っています。

## ガバナンス

XON 保有者は、ネットワークのガバナンスに参加できます。これには、アップグレードやネットワークの変更など、XODE Blockchain の運営や将来の方向性に関する提案への投票が含まれます。

## ステーキング

XON トークンは、XODE Blockchain のコンセンサスアルゴリズムに不可欠なステーキングメカニズムで使用されます。トランザクションを照合し、リレーチェーンに新しいブロックを追加することでネットワークの安全を守る役割を担うコレーターは、相当量の XON をステークする必要があります。ノミネーターも XON をステークして信頼するコレーターを支援でき、その見返りとして、それらのコレーターが獲得した報酬の一部を受け取ります。

## ボンディング

XON はボンディング、つまり流動性の提供に使用されます。LP（流動性プロバイダー）は、ペアとなる両方のトークンを同等の価値ずつプールに預け入れます。たとえば XON/USDT プールでは、LP は同等の価値の XON と USDT を預け入れます。

## 手数料

XODE Blockchain ネットワーク内のトランザクション手数料やその他の計算手数料は、XON を使用して支払われます。これにより、ネットワークリソースの効率的な利用が促進されます。

これらの機能により、XON は XODE Blockchain エコシステムに不可欠な存在となっており、エコシステムが安全かつ効率的に運用されると同時に、コミュニティが将来の開発に意見を反映できるようになっています。
